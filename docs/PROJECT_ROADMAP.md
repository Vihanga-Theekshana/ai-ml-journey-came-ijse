# From coursework to an internship portfolio

This repository documents learning. The next step is to develop one small, independently explained project with a clear problem and reproducible result. The ideas below are proposed extensions, not completed projects.

## First candidate: review sentiment classifier

Start from Day 13. Document the dataset source and sentiment-label definition, handle missing text, audit duplicate reviews across splits, and package preprocessing with the model in a scikit-learn pipeline. Compare a simple baseline with logistic regression. Report held-out precision, recall, F1, and a confusion matrix; discuss a few misclassified examples. Add a small prediction interface only after the evaluation is sound.

## Second candidate: retail customer segmentation

Start from Day 16. Explain the five customer features, justify scaling, compare cluster counts, describe cluster profiles in plain language, and explain limitations. Cluster labels alone do not prove useful business segments.

## Optional later candidate: neural-network training study

Start from Day 18 with the documented evaluation correction. Compare a simple baseline with the neural network using the same splits. Save reproducible configuration and learning curves. Label synthetic-data experiments explicitly and avoid real customer-performance claims.

## Definition of a finished portfolio project

- A specific problem and your own contribution.
- A documented dataset source and license.
- Repeatable setup and run commands.
- Appropriate splits, baseline, metrics, and error analysis.
- Results you can reproduce and explain in an interview.
- Limitations and a short demonstration.

Publish the finished project in its own repository and link it from this learning repository. Start with one complete project rather than listing several unfinished ideas as completed work.

## Honest CV wording now

“Organized an AI/ML learning portfolio covering Python, data analysis, regression, classification, clustering, and introductory PyTorch exercises.”

Add project-specific claims and measured results only after completing that work yourself.
